# @ownui/tw-theme

## 1.0.2

### Patch Changes

- 942ca24: # First Major Release - v1.0.0

  Initial stable release of @ownui/tw-theme with complete Tailwind CSS v4 plugin for semantic theming.

  ## Features

  - ✨ Semantic color system with 8 color tokens (primary, secondary, accent, neutral, info, success, warning, error)
  - 🎨 Automatic generation of CSS custom properties and utility classes
  - 🌓 Light and dark theme support with easy theme switching
  - 📦 Component-specific CSS generation for optimized imports
  - 🔧 Fully typed TypeScript API
  - ♿ Accessibility-focused with proper color contrast utilities
  - 🎯 React component integration with semantic class names

  ## Breaking Changes

  This is the first major release. Future breaking changes will be documented here.

  ## Migration

  This is the initial release, no migration needed.
